# java-login-signup-system
A console-based Login and Signup system developed using Java. This project allows users to create an account and authenticate using username and password validation
------------------------------------------------------
📌 Project Overview

This project is a console-based Secure Access System developed using Java.
It allows users to:
Sign up by creating a username and password,
Log in using saved credentials,
Validate authentication using string comparison,
The program demonstrates basic authentication logic in a simple command-line interface.
--------------------------------------------------------------------------------------

🚀 Features

✔️ User Signup,
✔️ User Login,
✔️ Username & Password Validation,
✔️ Error Handling for Invalid Login,
✔️ Account Existence Check,
✔️ Console-based Execution.

---------------------------------------------------------------------------------------

🛠️ Technologies Used

Java,
Scanner Class,
Conditional Statements (if-else),
String Comparison using .equals()

---------------------------------------------------------------------------------------

⚙️ How the Program Works

The system displays a menu:
1 → Sign Up,
2 → Login.

If the user selects Sign Up:
Username and password are stored temporarily.
The system asks the user to log in.
Credentials are validated.

If the user selects Login:
The system checks whether an account exists.
If credentials match → Login Successful.

Otherwise → Login Failed.
